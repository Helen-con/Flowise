# App Icons

This directory should contain the app icons:

- `icon-192x192.png` - 192x192 app icon
- `icon-512x512.png` - 512x512 app icon (maskable)

## Generating Icons

You can use tools like:
- https://realfavicongenerator.net/
- https://www.favicon-generator.org/

Or create custom icons using design tools and ensure they meet PWA requirements.

## Icon Requirements

- PNG format
- Transparent or solid background
- Square dimensions
- Optimized file size
- Follow Material Design guidelines for adaptive icons
